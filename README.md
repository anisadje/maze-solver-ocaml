## Membres

CHEKROUN Massylia

## Description
Ce projet, développé en OCaml, permet de **manipuler, générer aléatoirement, afficher et résoudre des labyrinthes** représentés sous forme de fichiers ASCII. Il met en application des algorithmes de parcours de graphes (BFS), de récursivité, de programmation fonctionnelle et une structure modulaire.

## Compilation
Le projet utilise le gestionnaire `dune`. Pour compiler, lancez la commande suivante à la racine :
```bash
dune build
