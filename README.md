# Projet Labyrinthe 

## Membres 
DJEDJE Anîsa 
CHEKROUN Massylia 

## Description 

Ce projet, développé en OCaml, a pour but de créer un programme en ligne de commande (`maze.exe`) capable de **manipuler, générer aléatoirement, afficher et résoudre des labyrinthes** représentés sous forme de fichiers ASCII-art. Il sert de cadre pour l'application d'algorithmes sur les graphes et l'utilisation de la programmation modulaire.
